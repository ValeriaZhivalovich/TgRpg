# ⚔️ TgRpg — Исекай-бот для геймификации задач

Telegram-бот в жанре **исекай** (попаданец в другой мир).  
Игрок регистрируется как персонаж, берёт квесты (задачи), прокачивает навыки, зарабатывает золото и XP, покупает предметы и заводит питомцев.

## Возможности

- 🧝‍♀️ **Регистрация** — 5 классов (Авантюрист, Маг, Воин, Торговец, Следопыт), имя/фамилия, emoji-аватар
- 📜 **Квесты** — создание задач с выбором сложности (Easy/Normal/Hard), типа (разовый/повторяющийся), навыка и дедлайна
- ⏱ **Верификация** — Easy (мгновенно), Normal (таймер 5 мин), Hard (таймер 10 мин + заметка/фото)
- 🔮 **Навыки** — 6 базовых навыков, XP распределяется между персонажем и навыком
- 🛍 **Рынок** — зелья (HP/EP/XP), свитки, корм для питомцев
- 🐾 **Питомцы** — 4 вида (котик, щенок, лисёнок, дракончик) с бонусами и уровнем
- 📝 **Заметки** — ручное создание + авто при Hard-квестах, поддержка фото, пагинация

## Команды

| Команда | Описание |
|---------|----------|
| `/start` | Начать регистрацию или вернуться |
| `/new_quest` | Создать новый квест |
| `/done` | Завершить квест |
| `/notes` | Открыть заметки |
| `/cancel` | Отменить текущее действие |

Кнопки меню: **Профиль**, **Список задач**, **Рынок**, **Боссы/Квесты**, **Настройки**

## Технологии

- Python 3.12+
- aiogram 3 — Telegram Bot API
- SQLAlchemy + aiosqlite — база данных
- python-dotenv — конфигурация

## Установка

```bash
git clone https://github.com/yourusername/TgRpg
cd TgRpg
python -m venv .venv
.venv\Scripts\activate    # Windows
pip install -r requirements.txt
```

Создай `.env` в корне проекта (см. `.env.example`):

```
TOKEN=your_telegram_bot_token_here
SQLALCHEMY_URL=sqlite+aiosqlite:///RbgBotDb.sqlite3
```

Запуск:

```bash
python bot.py
```
