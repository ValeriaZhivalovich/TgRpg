## 1. Концепция

### Идея в одном предложении
Telegram-бот, который превращает личные задачи в RPG-квесты в стиле аниме-исекай — с нарративом, режимами верификации и заметками прямо в процессе.

### Проблема

Habitica существует. Почему люди всё равно бросают?

Потому что геймификация без нарратива — это просто таблица с пикселями. Можно нажать "выполнено" не делая ничего. Система на чистом доверии не работает для людей с нестабильным самоконтролем. И ещё одно приложение — это ещё одно приложение.

### Решение

Три ключевых отличия от Habitica:

**1. Нарратив, а не скин**  
Бот — это не интерфейс с аниме-картинками. Это Система, которая с тобой разговаривает. Квесты выдаются с лором. Выполнение сопровождается реакцией Системы. Обмануть её *психологически некомфортно* — потому что она тебя "видит".

**2. Режимы верификации**  
Не все одинаково умеют держать себя в руках. Вместо одного режима "на честности" — три, на выбор пользователя. Подробнее в разделе 4.

**3. Telegram — там, где ты уже есть**  
Не надо открывать отдельное приложение. Бот живёт в мессенджере, который уже открыт.

## 3. Персонаж

При первом запуске (`/start`) Система "обнаруживает" пользователя и предлагает создать персонажа.

| Параметр | Описание |
|---|---|
| Имя | Задаётся пользователем |
| Фамилия | Опционально |
| Аватар | Emoji, задаётся пользователем или от класса |
| Класс | Авантюрист, Маг, Воин, Торговец, Следопыт |
| Уровень | Начинается с 1, растёт за XP |
| XP | Опыт за выполненные квесты |
| Золото | Валюта за квесты, тратится в магазине |
| HP | Здоровье, зависит от класса |
| EP | Энергия, зависит от класса |

Кастомизация: имя, фамилия, класс, emoji-аватар.

### Классы

| Класс | HP | EP | Стартовое золото | Особенность |
|---|---|---|---|---|
| 🗡️ Авантюрист | 100 | 50 | 0 | Сбалансирован |
| 🔮 Маг | 70 | 80 | 0 | Высокая энергия |
| ⚔️ Воин | 130 | 30 | 0 | Крепкое здоровье |
| 💰 Торговец | 90 | 50 | 50 | Начинает с золотом |
| 🏹 Следопыт | 100 | 60 | 0 | Вынослив и быстр |

При регистрации персонаж получает стартового питомца 🐱 Котик.

## 4. Режимы верификации ⚡

Главная механика, которой нет в Habitica. Пользователь выбирает режим под себя — и может его менять.

### Easy — режим доверия
Квест отмечается выполненным одной кнопкой. Никаких проверок.

### Normal — режим таймера
При старте квеста запускается таймер (5 мин). Завершить можно только после его истечения.

### Hard — режим подтверждения
Таймер (10 мин) + обязательная заметка или фото по завершении.

Глобальный режим задаётся в настройках (`⚙️ Настройки` или `/mode`) и влияет на предвыбор сложности при создании квеста. Пользователь может переопределить сложность для конкретного квеста.

---

## 5. Заметки 📝

- В **Easy** и **Normal** — заметку можно добавить к любому квесту по желанию (кнопка «📝 Добавить заметку» в списке активных квестов)
- В **Hard** — заметка обязательна для завершения квеста
- Отдельное создание заметок без привязки к квесту (`/notes`)
- Поддержка фото
- Пагинация (5 на страницу)

## 6. Квесты

| Поле | Описание |
|---|---|
| Название | Что нужно сделать |
| Сложность | Easy / Normal / Hard (влияет на награду) |
| Тип | Одноразовый или повторяющийся (привычка) |
| Навык | Привязка к навыку (опционально) |
| Дедлайн | Опционально |

За выполнение — XP и золото, зависящие от сложности.  
Повторяющиеся квесты имеют серию (`streak`) и сбрасываются ежедневно.

## 7. Питомцы 🐾

Спутники, которые путешествуют с героем. Дают пассивные бонусы, прокачиваются.

### Механика
- Один питомец может быть активен одновременно
- Питомец даёт пассивный бонус герою (формула: `base × (1 + (level−1) × 0.2)`)
- Питомец получает XP из квестов **только по совпадающим навыкам** (`skill_ids`)
- Питомца также можно кормить предметами из инвентаря (`pet_food`)
- Стартовый питомец выдаётся бесплатно при регистрации

### Питомцы

| Питомец | Бонус | Навыки для XP | Как получить |
|---|---|---|---|
| 🐱 Котик | +5 HP | Разработка, Бытовое | Стартовый / Магазин (30💰) |
| 🐶 Щенок | +5 EP | Обучение, Здоровье | Магазин (30💰) |
| 🦊 Лисёнок | +5% к XP | Обучение, Творчество | Достижение «10 квестов» |
| 🐉 Дракончик | +10 HP, +5 EP | Все навыки | Достижение «7 дней стрик» |
| 🐌 Слизень | Нет бонуса | — | Спрятанный квест (слово «слизень» в названии) |

### Прогрессия питомца
```
Квест со скиллом → XP питомца → Новый уровень → Усиление бонуса
Корм (pet_food) → XP питомца → Новый уровень → Усиление бонуса
```

Бонус растёт: `базовый_бонус × (1 + (уровень − 1) × 0.2)`

## 8. Прогрессия

```
Квест выполнен → XP → Новый уровень → Уведомление от Системы
```

Каждый уровень сопровождается текстом в стиле исекай.  
Достижения — разовые события, отслеживаются автоматически.

### Достижения

| Название | Условие | Награда |
|---|---|---|
| 🎯 Первый шаг | 1 квест | — |
| 🔥 Трудоголик | 10 квестов | 🦊 Лисёнок |
| 💀 Хардкорщик | Hard-квест | — |
| 📅 Неделя | 7 дней стрик | 🐉 Дракончик |
| ⬆️ Адепт | 5 уровень | — |
| ⬆️ Мастер | 10 уровень | — |
| 📝 Летописец | 5 заметок | — |
| 🐾 Друг зверей | 1 питомец | — |

## 9. Исекай-нарратив

Бот общается с пользователем как Система из аниме. Не "задача выполнена", а:

> *"Квест засчитан. Система фиксирует твой рост. +120 XP."*

> *"Уровень повышен. Мир чувствует изменения в тебе, Герой."*

> *"Таймер запущен. Система наблюдает."*

Все сообщения вынесены в `app/texts.py`.

## 11. Архитектура

### Стек
- Python 3.12+ · aiogram 3 · SQLAlchemy + aiosqlite · python-dotenv

### Структура БД (12 моделей)

**users** — `id, tg_id, username, last_name, mode (easy/normal/hard), created_at`

**characters** — `id, user_id, name, last_name, class_name, avatar, level, xp, gold, hp, energy`

**tasks** — `id, user_id, title, description, difficulty, type, deadline, status, started_at, completed_at, skill_id, reward_xp, reward_gold, last_completed_at, streak`

**notes** — `id, user_id, task_id (nullable), text, photo_id (nullable), created_at`

**skills** — `id, skill_name, level_max`

**user_skills** — `user_id, skill_id, xp, level`

**items** — `id, name, description, item_type, price, effect (JSON)`

**inventory_items** — `id, user_id, item_id, quantity, equipped`

**pets** — `id, name, description, price, stat_bonus (JSON), skill_ids (JSON), source (shop/achievement/easter_egg), achievement_code (nullable)`

**user_pets** — `id, user_id, pet_id, active, level, xp`

**achievements** — `id, code (unique), name, description, emoji, condition_type, condition_value`

**user_achievements** — `id, user_id, achievement_id, achieved_at`

### Структура проекта

```
TgRpg/
├── bot.py                         # Точка входа, seed-функции, фоновые уведомления
├── app/
│   ├── constants.py               # Enums и мапы
│   ├── keyboards.py               # Inline / Reply клавиатуры
│   ├── texts.py                   # Исекай-нарратив (все сообщения)
│   ├── notifications.py           # Фоновая проверка дедлайнов и привычек
│   ├── stats.py                   # Генерация графиков (matplotlib)
│   ├── database/
│   │   ├── models.py              # 12 SQLAlchemy моделей
│   │   └── request.py             # CRUD + seed-функции
│   └── handlers/
│       ├── user.py                # Регистрация, профиль, рынок, питомцы, настройки, команды, статистика
│       ├── quests.py              # FSM квестов, таймеры, завершение, заметки к квестам
│       └── notes.py               # Заметки, пагинация
├── logs/
│   └── logger_config.py
├── .env.example
├── README.md
└── requirements.txt
```
